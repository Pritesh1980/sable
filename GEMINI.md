# Sable — Agent Context

Read [`AGENTS.md`](AGENTS.md), then [`CLAUDE.md`](CLAUDE.md): together they are the project
context for every agent, not only Claude. This file exists so that tools which load
`GEMINI.md` by default (antigravity, the Gemini CLI) find them.

Other agents work in this repo at the same time. Run `npm run agents:status` before starting
anything, and follow **Working alongside other agents** in `CLAUDE.md`.
